🔴 ブラッドムーン 🗺️ 主要マップ別スポット
  • ゴースト名のタップ打ち消し: 各カードのゴースト名を直接タップすると、名前に打ち消し線が入りカード全体が薄くなります。消去法メモに最適！
  • 証拠・条件ボタン: 1回タップ：選択 / 2回タップ：除外 / 3回タップ：未選択

🔴 血月（ブラッドムーン）環境変化

  • ハント開始ラインが全ゴースト一律 +10% 上昇
  • ゴーストの移動速度が +15% (1.15倍) ブースト
  • 暗所での正気度減少速度が +100%（2倍） に加速

🗺️ 全マップ別：呪いアイテムの定番スポット

※アイテムはランダムですが、よくスポーンする代表的な場所です。

🏠 Tanglewood Street House (タングルウッド)
  • ガレージ: 車の横の棚や工具箱の上
  • リビング: テレビ台、ソファの横の小さなテーブル
  • 玄関 / 廊下: 入ってすぐ右のサイドテーブル
🏠 Edgefield Road (エッジフィールド)
  • 玄関ホール: 入ってすぐ正面の小テーブル
  • キッチン: カウンターの上や奥のダイニングテーブル
  • 廊下・階段下: 1階の廊下や階段脇のスペース
🏠 Ridgeview Court (リッジビュー)
  • ガレージ: 入ってすぐの棚や作業台の上
  • 地下室: 階段を下りた正面のフロア
  • プレイルーム (2階): 奥の部屋のゲーム機やテーブル付近
🏠 Willow Street (ウィロウ)
  • ガレージ: 入口すぐの作業台や棚
  • リビング: ソファ周辺やテレビ台の横
  • 主寝室 / 廊下: 1階奥の部屋のベッド脇や廊下
🏡 Grafton Farmhouse (グラフトン)
  • リビング: 1階中央の暖炉・テーブル周辺
  • 作業場: 1階奥の小部屋の棚
  • 2階廊下: 階段を上がってすぐのチェストの上
🏡 Bleasdale Farmhouse (ブリーズデール)
  • 作業場 (1階奥): ボイラー室の手前の棚
  • リビング / 廊下: 1階中央の大きなテーブルの上
  • 屋根裏への階段周辺: 2階から屋根裏へ上がる階段のふもと
⛺ Camp Woodwind (キャンプ・ウッドウィンド)
  • 受付カウンター: 入口ゲートを入ってすぐのチケット・売店カウンター上
  • 青いテント内: テントの床や簡易ベッドの上
  • トイレ付近: トイレ小屋の外側ベンチや周辺
🏕️ Maple Lodge Campsite (メイプルロッジ)
  • 管理棟 (キャビン): 入口付近のカウンターやテーブルの上
  • 休憩エリア: テントサイト付近のベンチやピクニックテーブル
  • トイレ・シャトールーム: 建物内の通路や小部屋
🏛️ Point Hope (ポイントホープ)
  • 1階エントランス: 入口付近の円形テーブルやカウンター
  • 中層階の部屋: 各階の居住スペースの棚やベッドサイド
  • 最上階: 灯台のてっぺんのフロアや機械周辺
🏫 Brownstone High School (ハイスクール)
  • ロビー / 受付: 正面玄関を入ってすぐのカウンター
  • 職員室: 1階のデスクや机の上
  • カフェテリア: 食堂の大きなテーブルの上
🧱 Prison (プリズン)
  • 面会室 / 受付: 入口からすぐのカウンターやロビー
  • 警備室: モニターが並ぶ部屋の机の上
  • 廊下 / ブロック: 独房エリアの通路やテーブル
🏥 Sunny Meadows / Restricted (サニーメドウズ)
  • チャペル (教会エリア): 中央の祭壇付近やベンチの上
  • 中庭周辺: 回廊のコーナーやテーブル
  • 受付・ロビー: 入口からすぐのカウンター
